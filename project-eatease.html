EatEase — Agentic AI for Restaurant Operations

Period: 2024–2025
Ownership: IBM client delivery
Role: Senior Application Architect / AI Engineer

Introduction

An AI-augmented layer on a traditional restaurant operations stack:

  • Customer web ordering: QR browse, customize, pay on phone
  • POS (tablet): order lifecycle, table/course management, inventory visibility for privileged roles
  • Admin console: menu/inventory, roles, reconciliation, promotions
  • Back-office AI assistant: dish images, multi-language names/descriptions, promo copy, ops report summaries
  • Front-office AI assistant: conversational discovery, dietary filtering, pairing suggestions, structured order placement via chat

My contribution

  • Architected front-office assistant with vector-backed semantic search for menu discovery and dietary filtering
  • Designed back-office assistant for media, multilingual content, and operational summarization
  • Led platform architecture across web ordering, POS, and admin with a unified BFF/API gateway
  • Implemented model orchestration connecting assistants with vector DB, media services, and task queues

Key technologies: Node.js, LLM APIs, vector DB, RAG, REST APIs, task queues, cloud-native services, real-time event processing, mobile web
